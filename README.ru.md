# PogodaApp

Погодное приложение для Android, созданное не разработчиком с помощью ИИ.

Мне не нравились существующие приложения для Германии, поэтому я решил сделать что-то своё. Приложение делается для работы в Германии и основывается на открытых источниках данных.

Пользуемся им я и друзья. Это личный проект, а не коммерческий продукт.

## Что умеет

- Погода как среда: фон из нарисованных картин неба, поверх него спокойный строгий интерфейс с матовым стеклом.
- Четыре вкладки: «Главная», «Прогноз», «Подробно», «Карта».
- Официальные предупреждения о погоде (DWD) с теми же уровнями и цветами.
- Индекс пыльцы DWD (8 видов) и качество воздуха по европейскому индексу EAQI.
- Радар осадков DWD на карте, от −2 до +2 часов.
- Уведомления о погоде и предупреждениях для текущего места.
- Виджеты на главный экран (2×2, 4×2, 4×4).
- Языки: русский, немецкий, английский.
- Каждый эффект можно отключить; режим энергосбережения Android выключает их сам.

## Откуда данные

| Данные | Источник | Лицензия / условия |
|---|---|---|
| Прогноз, качество воздуха | [Open-Meteo](https://open-meteo.com/) | [CC BY 4.0](https://open-meteo.com/en/licence), бесплатно только для некоммерческого использования |
| Пыльца, радар | [Deutscher Wetterdienst (DWD)](https://www.dwd.de/) | Datenbasis: Deutscher Wetterdienst (GeoNutzV) |
| Предупреждения | DWD через [Bright Sky](https://brightsky.dev/) | к данным применяются условия DWD; код Bright Sky под MIT |
| Поиск места | [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api), данные [GeoNames](https://www.geonames.org/) | CC BY 4.0 |

Приложение не связано с DWD, Open-Meteo и GeoNames и не одобрено ими.

## Установка

Требуется Android 16 или новее. Приложение проверялось только на Pixel 6 Pro и Pixel 7, на других телефонах работа не гарантируется.

1. Откройте раздел [Releases](../../releases) и скачайте файл `PogodaApp-<версия>.apk`.
2. Разрешите установку приложений из этого источника, когда система спросит.
3. Установите файл.

Удобнее поставить через [Obtainium](https://github.com/ImranR98/Obtainium): добавьте адрес этого репозитория, и обновления будут приходить сами.

Каждый выпуск подписан одним и тем же ключом, поэтому обновления ставятся поверх установленной версии.

## Важно знать

- Прогноз остаётся прогнозом. Не принимайте по нему решений, от которых зависят жизнь или безопасность; ориентируйтесь на официальные предупреждения DWD.
- Предупреждения и радар работают только для Германии. За границей приложение показывает прогноз и воздух, остальное пока «нет данных».
- Приложение пишет один человек с помощью ИИ, поэтому в нём бывают ошибки. Если что-то сломалось, заведите [issue](../../issues).
