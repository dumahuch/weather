# PogodaApp

Погодное приложение для Android (Kotlin, Jetpack Compose) для себя и друзей. Замена WetterOnline. Установка без магазина, обновления через GitHub Releases и Obtainium.

Стадия: версия 0.5.2. Есть главный экран (всё по центру: значок, температура, максимум и минимум дня, строка подписей) с почасовым прогнозом на нарисованном небе, прогноз по дням, вкладка «Подробно» (воздух, пыльца в Германии, ветер, давление, УФ, влажность, солнце и луна), поиск города по названию или индексу (найденный город открывается для просмотра, закрепляется кнопкой) и до пяти закреплённых мест. Карта (радар), уведомления и виджеты пока не сделаны. Дальше по одной функции, каждая версия проверяется на телефоне.

## Устройство проекта

- `app/`: приложение. Android 16 и новее (minSdk 36, целевая версия 36), только Pixel, только портрет. Языки: русский, немецкий, английский. Пакет `io.github.dumahuch.pogodaapp`.
- `.github/workflows/ci.yml`: при каждом изменении GitHub гоняет линт, тесты, сборку, разбирает готовый APK (пакет, версия, разрешения, языки, одноцветная иконка, подпись), собирает пробный релиз с одноразовым ключом и запускает приложение на эмуляторе Android 16 (установка, запуск, окно разрешения, главный экран с прогнозом и без сети, тексты на трёх языках, отсутствие падений).
- `.github/workflows/release.yml`: по кнопке «Run workflow» (или по метке `vX.Y.Z`) собирает подписанный APK из `main` и публикует его в Releases.
- `.github/scripts/`: скрипты этих проверок (часть с тестами).
- `release-notes/X.Y.Z.md`: текст выпуска для версии X.Y.Z (показывается в Obtainium).
- `design/`: материалы концепта (макет, документы, картины неба), см. ниже.

Данные погоды: Open-Meteo (https://open-meteo.com/), лицензия CC BY 4.0, ссылка на источник стоит в нижней строке главной. Поиск города: геокодер Open-Meteo (https://open-meteo.com/en/docs/geocoding-api), данные мест GeoNames (https://www.geonames.org/, CC BY 4.0), ссылка стоит на экране поиска.

Инструменты (проверены 28.10.2026): Gradle 9.7.1, Android Gradle Plugin 9.4.1, Kotlin 2.4.21, Compose BOM 2026.09.00. Версии лежат в `gradle/libs.versions.toml`.

## Номер версии

Из версии выпуска: `1.2.3` даёт `versionName 1.2.3` и `versionCode 1002003` (major × 1 000 000 + minor × 1 000 + patch). Для обновления номер должен расти.

## Выпуск новой версии

1. Изменения сливаются в `main`, проверка CI зелёная.
2. GitHub → Actions → слева «Release» → «Run workflow» (ветка `main`), в поле «version» ввести номер, например `0.1.0`, подтвердить. Сценарий сам собирает APK, создаёт метку `v0.1.0` и публикует выпуск (минуты). Если сборка упала до публикации, метки нет и версию можно запустить заново. Из сессии Claude метки отправить нельзя (git-прокси отвечает 403), поэтому основной путь ручной.
3. Obtainium у всех, кто поставил приложение, предложит обновиться.

Запуск от метки `vX.Y.Z` тоже работает, если метку отправить из другого места. Создавать выпуск через «Draft a new release» нельзя: релиз уже будет, и сборка упадёт на публикации.

## Ключ подписи (один раз)

Android принимает обновление только от приложения с той же подписью, поэтому ключ один на всю жизнь приложения. Он хранится в секретах репозитория (Settings → Secrets and variables → Actions → вкладка Secrets): `KEYSTORE_BASE64` (файл ключа, закодированный в base64) и `KEYSTORE_PASSWORD` (пароль). Имя ключа постоянное (`pogodaapp`), пароль ключа совпадает с паролем файла. В репозиторий ключ не попадает никогда (`.gitignore`). Копию файла и пароль хранить у себя. Отпечаток ключа записывается в описание каждого выпуска, и следующий выпуск сверяет его с прошлым: если ключ сменился, сборка останавливается.

## Материалы концепта (`design/`)

- `design/docs/`: договорённости по концепту (`concept-decisions.md`), промпты для картин неба (`sky-art-prompts.md`), инструкция по GitHub (`github-setup.md`), сборка, подпись и выпуск (`build-and-release.md`).
- `design/mockup/`: живой макет в браузере. Исходники в `src/`, картины неба для макета в `assets/` (1920×1280, WebP). Сборка командой `python3 build.py` создаёт `index.html` (6–7 МБ, в репозиторий не кладётся). Опубликованная версия лежит в проекте Claude. `make_assets.py` делает `assets/` из увеличенных файлов `design/sky/2x/`.
- `design/sky/`: картины неба для фона, шесть времён суток.
  - `original/`: как пришли из ChatGPT, 1536×1024.
  - `2x/`: увеличенные вдвое, 3072×2048, WebP.

## Названия картин неба

Время суток: `dawn` (7–8), `morning` (9–12), `afternoon` (13–16), `sunset` (16–18), `dusk` (18–19), `night` (20+).

- `sky_<время>.png`: панорама целиком.
- `sky_<время>_plate.png`: небо без облаков.
- `sky_<время>_clouds.png`: только облака, с прозрачностью.

## Как увеличены картины

Скрипты в `design/sky/tools/`. Панорамы и облака: Real-ESRGAN (модель `RealESRGAN_x4plus_anime_6B`, лицензия BSD-3-Clause, https://github.com/xinntao/Real-ESRGAN), результат смешан на 65 % с обычным увеличением, чтобы остались мягкие мазки. Небо без облаков увеличено обычным способом. Файл модели в репозиторий не входит.
