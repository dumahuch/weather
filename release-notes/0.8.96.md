Сборка и виджет: ничего видимого.

- Окно настройки виджета принимает только номера наших виджетов: чужое приложение больше не может открыть его с выдуманным номером.
- Сверка ключа подписи при выпуске идёт по файлу в репозитории, а не по тексту прошлого описания выпуска, которое можно поправить руками.
