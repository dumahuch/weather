 - Погода в шторке уведомлений и температура в строке состояния. Включаются в настройках, в новой карточке «Уведомления»; по умолчанию выключены. При первом включении Android спросит разрешение на уведомления.
 - Уведомление показывает место, температуру, погоду, «Ощущается как» и осадки на сегодня. Обновляется в фоне примерно раз в полчаса; ночью и при экономии батареи Android делает это реже. Смахнутое уведомление вернётся при следующем обновлении.
 - Место берётся то, где вы последний раз открывали приложение: постоянного доступа к местоположению приложение не просит. Если приложение не открывали больше суток, в уведомлении написано «Место с 5 ноября».
 - На заблокированном экране по умолчанию видны только температура и погода, без названия места. Название можно включить в настройках.
 - Новые разрешения: уведомления (спрашивается) и запуск после перезагрузки телефона (чтобы обновление уведомления не останавливалось).
