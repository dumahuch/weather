На вкладке «Подробно» появилась плитка «Пыльца»: четыре вида с самой высокой нагрузкой на сегодня в вашем районе по данным Немецкой метеослужбы (DWD), по три точки на вид, половина точки для промежуточных уровней. Работает только в Германии, в других странах плитка показывает «Нет данных». Плитка качества воздуха стала вдвое уже и стоит рядом с пыльцой.
