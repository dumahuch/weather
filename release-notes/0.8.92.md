Легче стекло и страница ветра.

- Небо под стеклом рисуется один раз на кадр для всех карточек, а не заново для каждой: по замеру почти вся цена прокрутки и переходов была в стекле.
- Ветряк крутит только слой с лопастями: страница больше не собирается и не перерисовывается заново 120 раз в секунду, пока открыта.
