 - Новое: уведомление «Скоро дождь». Если по радару DWD в ближайший час начнётся дождь не слабее 0,5 мм/ч, приходит уведомление «Дождь начнётся примерно через N мин». Включается в настройках («Уведомления»), по умолчанию выключено. Только Германия; проверяется примерно раз в полчаса, поэтому время приблизительное. Об одном дожде одно уведомление.
