 - Новое: предупреждения DWD уведомлениями. В настройках «Уведомления» → «Предупреждения о погоде» (по умолчанию выключено). Примерно раз в полчаса приложение проверяет официальные предупреждения для места, где его последний раз открывали, и сообщает о новых со звуком. Только для мест в Германии.
 - Об одном и том же предупреждении второй раз не сообщается, даже если DWD его уточнил. При повышении уровня придёт новое уведомление. Когда предупреждение кончилось или отменено, уведомление убирается само.
 - Нажатие на уведомление открывает приложение на этом предупреждении.
 - На заблокированном экране уведомление без названия района.
 - Новых прав нет.
