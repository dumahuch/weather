- Карта, слой «Ветер»: вместо стрелок цветная заливка по силе ветра (приглушённые цвета, шкала 20 / 40 / 60 / 80 км/ч) и тонкие линии, которые бегут по ветру и тают. При сильном ветре линии быстрее, ярче и чуть толще. Пока карту двигают пальцем, линий нет; они появляются снова, когда карта остановилась.
