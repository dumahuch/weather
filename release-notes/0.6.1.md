- Новый фон «Ди»: слоистые бумажные горы. Включается в Настройки → Фон; по умолчанию остаётся прежний «Нейтральный».
- Горы сдвигаются по времени суток и при прокрутке экранов (ближние гряды сильнее дальних), облака собраны из отдельных бумажных облаков и подкрашены под время суток.
- Экран проверки неба (семь нажатий на номер версии) снова есть в обычной сборке.
- В эту версию входят и предупреждения DWD из 0.6.0 (она не выпускалась отдельно).
- Приложение стало больше примерно на 13 МБ (картины «Ди»).
- Солнца и луны во «Ди» пока нет, они будут в следующих версиях.
