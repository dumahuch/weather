 - Исправлено: при включении «Температуры в строке состояния» приложение падало и больше не открывалось. Число в строке состояния теперь собрано из готовых значков, а не рисуется картинкой: такой значок Android не принимал.
 - Если после 0.7.0 приложение не открывается: Настройки телефона → Приложения → PogodaApp → Уведомления → выключить, открыть приложение, обновить до 0.7.1 и включить уведомления обратно.
