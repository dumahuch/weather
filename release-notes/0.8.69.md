- Обновление из самого приложения, без Obtainium: в настройках новый раздел «Обновления». «Проверить сейчас» смотрит последний выпуск на GitHub; если вышла новая версия, появляется «Установить X.Y.Z»: файл скачивается, сверяется с контрольной суммой GitHub и передаётся системе.
- Выключатель «Проверять раз в сутки» (по умолчанию включён): при новой версии приходит тихое уведомление, по нажатию открывается раздел «Обновления».
- В первый раз Android попросит разрешить установку из этого приложения («Установка неизвестных приложений»). Дальше приложение обновляет само себя; окно подтверждения система показывает, только если сочтёт нужным. После установки приходит уведомление «PogodaApp обновлён до X.Y.Z».
- Новые права: установка приложений (только себя) и обновление себя без окна подтверждения. Новый адрес: api.github.com (запрос без места), файл с github.com. Obtainium продолжает работать параллельно.
