# Небо для PogodaApp: набор слоёв (WebP)

Стиль: слоистая бумага, 3D, яркая гамма. Шесть времён суток: day, morning, dawn, sunset, twilight, night. Время суток выбирает палитру, облачность выбирает облака, дождь, туман, снег и молнию рисует код поверх.

## Папки
- `sky_webp/` lossless (бит в бит как PNG), около 55 МБ. Мастер-копия.
- `sky_webp_q95/` mountain и облака lossy q95 (средняя ошибка около 1.7 из 255, на бумажной фактуре не видна), небо lossless. Около 14.5 МБ. Это для приложения.
Имена подходят для Android-ресурсов (маленькие буквы, подчёркивания, без цифр в начале).

## Горные слои: `{scene}_{layer}.webp`
Размер 1024x1536, RGBA. Порядок сзади вперёд: `sky`, `far`, `mid`, `yellow`, `coral`, `front`.
- Композиция (гребни) одинаковая во всех шести сценах, слои разных сцен взаимозаменяемы по форме. Координаты гребней: `ridges.json` (y верхнего края каждого слоя по столбцам x=0..1023; far около 727-825, front около 1236-1342).
- Каждый слой сплошной до нижнего края холста, скрытые части достроены зеркалом, при сдвиге дыр нет. Верхняя светлая кромка входит в слой.
- `sky` непрозрачное, без гор, ниже линии гор достроено градиентом.
- Склейка слоёв воспроизводит исходную сцену (расхождение меньше 1% пикселей, только кромки).

## Параллакс
Слои растянуть шире экрана на 10-15% (иначе при сдвиге проступает край). Рабочие сдвиги между соседними слоями около 20-40 px на холсте 1024; пример проверки: far -8, mid -20, yellow -34, coral -50, front -70 px. Дальние медленнее, ближние быстрее.

## Облака: `cloud_light_01..08.webp`, `cloud_storm_01..06.webp`
Отдельные спрайты, RGBA, обрезаны по контуру, разные размеры. Светлые подкрашиваются кодом под время суток, грозовые для пасмурно, дождя и грозы. Количество и скорость по проценту облачности.

## Солнце и луна
Холст 1254x1254, диск луны: центр около (619, 630), диаметр около 664 px, все фазы на одном холсте и в одном положении. Свечение рисует код (в файлах его нет у фаз).
- `sun.webp`: три кольца, со свечением.
- `moon_full.webp` (со свечением), `moon_gibbous_*`, `moon_quarter_*`, `moon_crescent_*`: `waxing` освещена справа, `waning` слева (северное полушарие, Германия).
- Новолуние: луны нет. Фаза считается по дате, интернет не нужен. Показываем ночью и в сумерках.

## Известные ограничения
- Градиент неба в кадре один на сцену, переходы между временами суток делает код (плавное смешивание слоёв).
- Исходные PNG и промпты: папка `Обои v.2`, промпты в `claude/sky-art-prompts.md` проекта.
