# GitHub для WeatherApp: пошаговая инструкция (27 октября 2026, обновлено 28 октября)

Названия кнопок на GitHub английские, в инструкции они в кавычках. Шаги 1–3 выполнены 27 октября. Код шага 0 лежит в main с 28 октября, ключ подписи создан, теперь нужен шаг 4 (два секрета). Подробности о сборке и выпуске: claude/build-and-release.md.

Репозиторий dumahuch/weather подключён к сессии Claude с правом записи (27 октября).

## Сейчас

### 1. Создать репозиторий
1. Открыть github.com и войти.
2. Нажать «+» вверху справа, затем «New repository».
3. «Repository name»: `weather` (латиницей, без пробелов).
4. «Public» (рекомендую) или «Private»:
   - Public: исходники видны всем, но ключ подписи и пароли лежат отдельно и не видны. Бесплатная сборка без лимитов. Друзья ставят обновления через Obtainium без всяких ключей.
   - Private: работает, но для Obtainium каждому другу понадобится ключ доступа GitHub (токен). Эту часть я не проверял. Лимит бесплатной сборки у закрытых репозиториев ограничен по минутам.
5. Поставить галочку «Add a README file».
6. Нажать «Create repository».

### 2. Дать доступ Claude к репозиторию
1. Открыть https://github.com/apps/claude/installations/new.
2. Выбрать свой аккаунт.
3. «Only select repositories», выбрать `weather`.
4. Нажать «Install» (если приложение уже стоит, вместо этого откроется «Configure», там в «Repository access» добавить `weather` и нажать «Save»).

### 3. Написать мне имя репозитория
Одной строкой в чат: `твойлогин/weather`. Я подключу его к сессии с правом записи и проверю доступ. Если не увидит, значит на шаге 2 репозиторий не отметился. Тогда проверь ещё claude.ai, «Settings», «Connectors»: GitHub должен быть подключён.

Первым делом я положу туда исходники макета, документы концепта и картины неба (папка `design/sky/`). Оригиналы картин должны жить в репозитории, а не только в чате.

## Позже, когда начнём код

### 4. Ключ подписи (28 октября)
Android принимает обновление только от приложения с той же подписью. Ключ один на всю жизнь приложения.
1. Я создал ключ и отдаю тебе два файла: `pogodaapp-release.p12` (сам ключ) и `signing-secrets.txt` (два значения для GitHub). Сохрани оба в менеджер паролей сразу. Потеряешь ключ: друзьям придётся удалить приложение и поставить заново, закреплённые места пропадут.
2. Открой https://github.com/dumahuch/weather/settings/secrets/actions, нажми «New repository secret». Нужно два секрета, имена точно такие:
   - `KEYSTORE_PASSWORD`: в поле «Secret» вставить пароль из файла `signing-secrets.txt`, «Add secret».
   - `KEYSTORE_BASE64`: в поле «Secret» вставить длинную строку из того же файла целиком (одна строка, без пробелов и переносов), «Add secret».
3. Запустить выпуск: https://github.com/dumahuch/weather/actions → слева «Release» → кнопка «Run workflow» (ветка `main`) → в поле «version» ввести `0.0.1` → зелёная кнопка «Run workflow». Через 5–10 минут во вкладке «Releases» появится `PogodaApp-0.0.1.apk`. Следующие версии запускаются так же (0.0.2 и дальше). Метку я поставить не могу (git-прокси сессии отвечает 403), поэтому запуск делаешь ты.

Имя ключа (`pogodaapp`) постоянное и лежит в сценарии, пароль ключа совпадает с паролем файла: поэтому секретов два, а не четыре.

### 5. Выпуск версии
Выпуск запускается кнопкой в GitHub (шаги ниже) или мной, если у меня будет право ставить метки. GitHub сам собирает подписанный APK за несколько минут и кладёт его в «Releases». Ты ничего не нажимаешь. Если пометка из моей сессии не сработает, вручную: репозиторий, «Releases» справа от списка файлов, «Draft a new release», в «Choose a tag» ввести v0.0.1 и «Create new tag», «Publish release». Сборка запустится после этого.

### 6. Поставить на свой телефон
1. Открыть на телефоне страницу репозитория, «Releases», скачать файл `.apk` последней версии.
2. Открыть его. Android попросит разрешить установку из этого источника (браузера), разрешить.
3. Если Play Protect спросит, что делать, выбрать установку без проверки.

### 7. Друзьям и обновления
1. Друг ставит Obtainium: APK берётся со страницы https://github.com/ImranR98/Obtainium/releases (или из F-Droid, или IzzyOnDroid).
2. В Obtainium «Add App», вставить ссылку на твой репозиторий `https://github.com/твойлогин/weather`, «Add», затем «Install».
3. Новые версии Obtainium заметит сам, когда в «Releases» появится релиз, и предложит обновить.
4. Проверка разработчиков Android (Google): принудительная с 30 сентября 2026 только в Бразилии, Индонезии, Сингапуре и Таиланде, во всём мире в 2027 году. Для друзей и себя есть бесплатный аккаунт «ограниченное распространение»: до 20 устройств, без паспорта (нужны Google-аккаунт с двухэтапной проверкой и платёжный профиль). Зарегистрироваться до включения проверки в Германии (дату перепроверить).
