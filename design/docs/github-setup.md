# GitHub для WeatherApp: пошаговая инструкция (27 октября 2026)

Названия кнопок на GitHub английские, в инструкции они в кавычках. Кода приложения ещё нет, поэтому сейчас нужны только шаги 1–3. Шаги 4–7 понадобятся, когда начнём писать приложение.

На 27 октября сессия Claude видит 0 репозиториев: подключение GitHub есть, а репозитория, к которому у Claude есть доступ, пока нет.

## Сейчас

### 1. Создать репозиторий
1. Открыть github.com и войти.
2. Нажать «+» вверху справа, затем «New repository».
3. «Repository name»: `weather` (латиницей, без пробелов).
4. «Public» (рекомендую) или «Private»:
   - Public: исходники видны всем, но ключ подписи и пароли лежат отдельно и не видны. Бесплатная сборка без лимитов. Друзья ставят обновления через Obtainium без всяких ключей.
   - Private: работает, но для Obtainium каждому другу понадобится ключ доступа GitHub (токен). Эту часть я не проверял. Лимит бесплатной сборки у закрытых репозиториев ограничен по минутам.
5. Поставить галочку «Add a README file».
6. Нажать «Create repository».

### 2. Дать доступ Claude к репозиторию
1. Открыть https://github.com/apps/claude/installations/new.
2. Выбрать свой аккаунт.
3. «Only select repositories», выбрать `weather`.
4. Нажать «Install» (если приложение уже стоит, вместо этого откроется «Configure», там в «Repository access» добавить `weather` и нажать «Save»).

### 3. Написать мне имя репозитория
Одной строкой в чат: `твойлогин/weather`. Я подключу его к сессии с правом записи и проверю доступ. Если не увидит, значит на шаге 2 репозиторий не отметился. Тогда проверь ещё claude.ai, «Settings», «Connectors»: GitHub должен быть подключён.

Первым делом я положу туда исходники макета, документы концепта и картины неба (папка `design/sky/`). Оригиналы картин должны жить в репозитории, а не только в чате.

## Позже, когда начнём код

### 4. Ключ подписи
Android принимает обновление только от приложения с той же подписью. Ключ один на всю жизнь приложения.
1. Я создаю ключ и даю тебе четыре значения: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
2. Ты открываешь репозиторий, «Settings», слева «Secrets and variables», «Actions», вкладка «Secrets», «New repository secret». Для каждого значения: имя точно как выше, в поле «Secret» значение, «Add secret».
3. Сохрани копию всех четырёх значений у себя (менеджер паролей или заметка с паролем). Потеряешь ключ: друзьям придётся удалить приложение и поставить заново, закреплённые места пропадут.

### 5. Выпуск версии
Я помечаю готовую версию (например v0.1.0). GitHub сам собирает подписанный APK за несколько минут и кладёт его в «Releases». Ты ничего не нажимаешь. Если пометка из моей сессии не сработает, вручную: репозиторий, «Releases» справа от списка файлов, «Draft a new release», в «Choose a tag» ввести v0.1.0 и «Create new tag», «Publish release». Сборка запустится после этого.

### 6. Поставить на свой телефон
1. Открыть на телефоне страницу репозитория, «Releases», скачать файл `.apk` последней версии.
2. Открыть его. Android попросит разрешить установку из этого источника (браузера), разрешить.
3. Если Play Protect спросит, что делать, выбрать установку без проверки.

### 7. Друзьям и обновления
1. Друг ставит Obtainium: APK берётся со страницы https://github.com/ImranR98/Obtainium/releases (или из F-Droid, или IzzyOnDroid).
2. В Obtainium «Add App», вставить ссылку на твой репозиторий `https://github.com/твойлогин/weather`, «Add», затем «Install».
3. Новые версии Obtainium заметит сам, когда в «Releases» появится релиз, и предложит обновить.
4. Проверка разработчиков Android (Google) с 2027 года: до 20 устройств бесплатно. Условия для Германии я перепроверю перед первым релизом.
