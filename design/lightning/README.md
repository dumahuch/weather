# Молнии: картинки

`app/src/main/assets/lightning/bolt_01…06.webp`: шесть молний. Сгенерировал Дима 14.11.2026 в ChatGPT по запросу
«a single realistic lightning bolt striking from the top of the frame, pure white-blue core with thin branches,
completely pure black background, no clouds, no glow halo» (вертикально 1024×1536). Права на использование в приложении у Димы.

Обработка (скрипт не хранится, шаги простые): прозрачность = (наибольший из каналов − 0,035) / 0,965, цвет = цвет / наибольший
канал; обрезано пустое поле слева, справа и снизу (верх у всех молний у края кадра, поэтому не обрезается);
WebP с прозрачностью, качество 92. Поверх неба обычное наложение такой картинки почти совпадает с «экраном» исходной на чёрном.

Как рисуется: расписание `sky/Lightning.kt`, рисование `ui/sky/LightningArt.kt` (молния между облаками и грядами, свет поверх неба).
